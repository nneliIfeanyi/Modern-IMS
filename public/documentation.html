Getting Started

  1. Login at login.html using an authorized account.
  2. Use Dashboard for KPIs and recent movement visibility.
  3. Create and manage masters first: Products, Warehouses, Suppliers.

Core Flows

  • Inbound: Purchase Orders -> Send -> Receive to increase stock.
  • Outbound: Sales Orders -> Confirm -> Fulfill to decrease stock.
  • Direct Adjustments: Use Stock Movements with strict negative-stock guard.

Roles

  • Admin/Manager: Access Suppliers, Reports, and Settings.
  • Staff: Operational modules only; restricted from admin/manager areas.

Troubleshooting

  • If login succeeds but page does not move, refresh and ensure session cookies are enabled.
  • If data pages fail to load, confirm app is served from public/ root and API routes are reachable.
  • For server errors, inspect storage/logs/app.log.
