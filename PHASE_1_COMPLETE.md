## 💡 Customization Guide

### Quick Changes

**Change Headline:**
```html
<h2>Smart solutions for your <em>home.</em></h2>
```

**Change Button Link:**
```html
<a href="electronics.html" class="btn btn-electronics">
```

**Change Colors:**
```css
:root {
    --blue-900: #YOUR_COLOR_HERE;
    --blue-700: #YOUR_COLOR_HERE;
}
```

**Add Product Categories:**
```html
<p class="text-muted">Browse our wide selection of TVs, refrigerators, 
   washing machines, home theatre systems, blenders and more.</p>
```
